# Negative findings and archive routes

**Covers**: searches that found no readable measurement, the sources checked, and the route that
remains. Read this before commissioning a research pass so that a negative result is not paid for
twice. Current treatments are in [handoff](handoff.md); the research-report index is in
[vehicle-cost-evidence](../vehicle-cost-evidence.md).

## How to use this file

- **UNAVAILABLE** means the source exists but could not be read in the pass. Do not search the same
  web surface again; a new attempt needs a changed access route: an archive visit, a digitisation,
  a different repository, or a new publication.
- **NO MEASUREMENT** means the source was read and does not contain the figure. Do not search it
  again.
- **CLOSED** means the question was answered and needs no further research.
- Record the date and the route in the research report; update this file when a route closes.
